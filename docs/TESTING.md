# Этап 8. Тестирование

Roblox Studio в облачной среде разработки недоступен, поэтому игра проверялась тремя способами.
**В настоящем Roblox Studio игра ещё не запускалась** — первый запуск у вас (см. «Что проверить в Studio»).

## 1. Статический анализ (luau-lsp + определения Roblox API)

```
rojo sourcemap default.project.json -o sourcemap.json
luau-lsp analyze --definitions=globalTypes.d.luau --sourcemap=sourcemap.json --no-strict-dm-types src
```
Результат: **0 ошибок** во всех 60 модулях.

## 2. Юнит-тесты логики и конфигов — `lune run tests/run.luau`

**414 проверок, 0 провалов.** Покрыто: целостность конфигов (ссылки, нормализация шансов, непрерывность зон,
рост цен улучшений), WeightedRandom (включая распределение на 20 000 бросков), форматирование чисел/времени,
рост и голод (сытый/голодный/офлайн-кап/хранилище/кап Adult), кормление (блок сытости, тоник, Starfruit → Ascended),
экономика (инкубация, ускорение, бонусы черт и индекса), профиль (сверка битых сохранений, идемпотентность, uid),
контракт клиент–сервер (у каждого действия есть обработчик, каждый счётчик задания увеличивается).

(они проверяют имена свойств и типы), эмулирует события, Remote-вызовы, DataStore, время и игроков.

## 4. Предпросмотр интерфейса

`tools/preview` выгружает собранное в эмуляторе дерево GUI в JSON и рисует его в Chromium (`docs/preview/*.jpg`).
Это **приближение** (3D-превью существ заменены значками), но раскладка, цвета, шрифты и обводки соответствуют коду.

## Что проверить в Studio (не проверено автоматически)

1. Физика: отбрасывание после удара/стража, оглушение, движение стражей.
2. Отрисовка студов (`SurfaceType.Studs`), шрифт Nunito для кириллицы, превью во ViewportFrame.
3. Встроенные звуки `rbxasset://sounds/...` (если какого-то нет — просто тишина).
4. Мобильное управление: тап по подсказкам, бита, масштаб UI на телефоне.
5. Нагрузка с 6 игроками (Game Settings → Max Players = 6).
6. DataStore: в Studio включить Game Settings → Security → Enable Studio Access to API Services.

## Известные ограничения

- Fuse Machine, трейлы, маунты, капканы и Robux-товары из референсов не реализованы (вне MVP).
- Тест отказа DataStore (5 повторов с паузами до 16 с) не автоматизирован из-за длительности.
- Античит скорости клиента не реализован: WalkSpeed задаёт сервер, но эксплойт-клиент может двигаться быстрее.
