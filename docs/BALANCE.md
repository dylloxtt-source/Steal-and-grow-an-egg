# Баланс

Все числа — в `src/shared/Config/*.luau`. Таблицы ниже выведены командой `lune run tools/tables.luau`.

## Экономика (`Config/Economy`)

| Параметр | Значение |
|---|---|
| Стартовые деньги | $1,000 каждому игроку |
| Награда за убийство | каждому игроку матча (нет «кражи убийств»), +6 % за каждую волну |
| Бонус за волну | 150 + 45 × номер волны, каждому |
| Бонус за босса | +$250 каждому |
| Продажа | 60 % от всего потраченного (покупка + улучшения) |
| Лимит башен | 15 на игрока |
| Гемы (сохраняются) | 5 за волну + 0,15 за убийство, ×сложность карты; +150 × сложность за победу |
| Опыт | 10 за волну × сложность, +200 за победу; уровень = 250 + 150 × уровень опыта |

## База: 3 жизни

У базы 3 жизни. Любой враг, дошедший до базы, отнимает одну жизнь — обычный, элитный и босс одинаково.
Третий прорыв — поражение. Подкрепление боссов (рыцари Джаггернаута и Варлорда) выходит из портала,
а не рядом с базой: иначе при 3 жизнях это было бы нечестно.

## Магазин башен

Новый игрок владеет только мечником. Остальные башни покупаются за гемы один раз навсегда;
в матч берётся набор до 5 башен (`Towers.LoadoutSize`). Цены — поле `Price` в `Config/Towers`.

| Башня | Редкость | Цена |
|---|---|---|
| Swordsman | Starter | бесплатно (есть у всех) |
| Archer | Common | 💎 50 |
| Pistol Shooter | Common | 💎 250 |
| Toxic Shooter | Uncommon | 💎 450 |
| Sniper | Rare | 💎 700 |
| Lumberjack | Rare | 💎 900 |
| Machine Gunner | Epic | 💎 1,300 |
| Wolverine | Legendary | 💎 2,000 |

Темп: новичок с одним мечником соло доходит до 9-й волны на Greenfield (там первые скрытные враги,
а мечник видит их только с 4-го уровня). Это ≈55 гемов — хватает на лучника (50) после первого же матча.
Победа на Greenfield даёт ≈300 гемов. Вся коллекция — около 5650 гемов.

Рост по волнам (`Config/Waves`): здоровье × 0,8 × (1 + 0,05n + 0,0045n²), где n = (волна − 1) × 1,5;
скорость до +25 %, броня +1 каждые 7 волн (только у бронированных). Боссы не масштабируются волной.
Сложность карты усиливает врагов постепенно (полностью к 10-й волне), за каждого игрока сверх первого +50 % HP.
Волны после 20-й генерируются автоматически (`Waves.Get(n)`), достаточно поднять `Waves.Max`.

## Результаты балансного прогона

Команда: `lune run tests/balance.luau <игроков>`. Бот-«средний игрок» каждую секунду делает самое выгодное
из доступных по деньгам действий (наибольший прирост DPS на монету: поставить следующую башню из фиксированного
порядка или улучшить), снайперам ставит приоритет Strongest. Тактик он не знает, поэтому живой игрок обычно сильнее.

| Игроков | Greenfield | Desert | Snow | Ruins | Neon |
|---|---|---|---|---|---|
| 1 | победа (2/3 жизни) | победа (2/3) | победа (2/3) | поражение на 17-й | поражение на 12-й |
| 2 | победа (3/3) | победа (2/3) | победа (3/3) | победа (2/3) | победа (2/3) |

Только стартовый мечник (`lune run tests/balance.luau <игроков> greenfield starter`): поражение на 9-й волне
и соло, и вдвоём — первые скрытные враги. Это стимул купить лучника (50 гемов, видит скрытных с 3-го уровня).

Задумано так: соло проходятся три лёгкие карты, Ruins и Neon рассчитаны на группу. Матч длится 14–25 минут.
Это симуляция, а не замена плейтеста: стоит сыграть в Studio и подстроить числа под ощущения.
